Conditionals

Bedingungen und mögliche Folgen ausdrücken.

Niveau 1

Zero Conditional: if + Present Simple, Present Simple. Für allgemeine Regeln.

If you heat ice, it melts.

Niveau 1 üben →

Niveau 2

First Conditional: if + Present Simple, will + Grundform. Für reale zukünftige Möglichkeiten.

If it rains, we will stay home.

Niveau 2 üben →

Niveau 3

Second: if + Past Simple, would + Grundform. Third: if + Past Perfect, would have + past participle.

If I had more time, I would read more.
